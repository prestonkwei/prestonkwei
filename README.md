Hi, I’m Preston. I build AI agents and the infrastructure they run on.

The first was an assistant that read my inbox and booked meetings for me. Next, I built one that makes outbound phone calls and holds a real speech-to-speech conversation. Another one ordered a pizza and paid with a single-use virtual card (I happened to win a hackathon with that one). I built that one mostly to see what breaks when an agent has to spend real money.

Now I spend more of my time on what sits underneath them: the memory and context services they read from, the messaging gateways they send through, and the pipelines that let them run on a schedule instead of waiting for me to ask.

I also work on identity and auth, developer tooling, and a few internal platforms that people use every day.
